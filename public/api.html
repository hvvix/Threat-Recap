Data API & RSS feeds

Everything on this site is built from plain static files that anyone can use for free: no key, no sign-up, CORS enabled. They're rebuilt about every 20 minutes, so checking more often than that just returns the same data — a 15–20 minute interval is plenty. The generated timestamp in each file tells you when it last changed.

Example: exploited CVEs for a vendor

const { kev } = await (await fetch('data/cves.json')).json();
console.log(kev.filter(k => k.v === 'Fortinet'));

Upstream data belongs to its publishers: CISA (KEV), NIST NVD, MITRE CVE, FIRST (EPSS), nomi-sec/PoC-in-GitHub, ransomware.live, Have I Been Pwned, GitHub Advisory Database and each news source. Headlines link to the original articles.
